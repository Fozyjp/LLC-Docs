# Light Limit Changer V1 → V2 移行ガイド

:::info
Light Limit Changer v1.x.x は **v1.14.4 をもちましてサポートを終了**しております。  
今後のアップデートや不具合修正は行われません。新規導入・乗り換えには LLC v2 の使用を推奨します。
:::

:::note
*LLC : Light Limit Changer for MA
:::

## LLC V2 に移行するメリット

### パラメーター消費量の大幅削減

LLC V2 はパラメーター圧縮機能により、LLC V1 と比べてパラメーター消費量を大幅に削減しています。

| バージョン | 最大消費パラメーター数 |
|:---:|:---:|
| V1 | 49 |
| V2 | **16** |

:::info
VRChat のアバターには **Expression Parameter の使用上限が 256bit** という制約があります。  
パラメーターが少ないほど、他のギミックや衣装ツールに使えるパラメーターの余裕が増え、アバターの表現の幅が広がります。  
V2 の圧縮機能を使うことで、V1 の約 1/3 のパラメーター消費に抑えることができます。
:::

### LLC V2 専用の新機能

LLC V2 では以下の機能が新たに追加されています。

- 逆光ライト・光源の向き制御
- 色相・明度・ガンマ*調整
- lilToon：影環境強度・頂点ライト・距離フェード
- Poiyomi：明るさ上限のAddPass分離*・ライトのモノクロ化のAddPass分離*・PP Animation*
- 動的プリセット機能*
- Anchor Override / Bounds 統一機能*
- 消費VRAM低減機能

<details>
    <summary> *用語解説 </summary>

**AddPass分離とは？（Poiyomi）**  
Poiyomi シェーダーには、通常の描画パス（BasePass）に加えて加算合成用の描画パス（AddPass）があります。  
AddPass分離を有効にすると、ポイントライトなど加算光源が当たる環境での明るさ上限・モノクロ設定を、通常環境とは独立して制御できるようになります。

**PP Animation とは？（Poiyomi）**  
Post Processing Animation の略で、Poiyomi の特定プロパティをアバター側からアニメーション制御する機能です。  
LLC v2 ではこの仕組みを使って明るさ設定をリアルタイムに反映します。

**動的プリセットとは？**  
アバターのExpressionメニューからリアルタイムにプリセット（設定の組み合わせ）を切り替えられる機能です。  
V1 のプリセットはビルド時に固定されていましたが、V2 ではワールドの環境に合わせてプレイ中に切り替えることができます。

**Anchor Override / Bounds とは？**  
Unity がメッシュの明るさ・陰影を計算する基準点（Anchor）とサイズ（Bounds）の設定です。  
アバターの各パーツでこれがバラバラになっていると、パーツごとに明るさが異なって見える「ちらつき」が発生することがあります。LLC の統一機能でこれをまとめて修正できます。

</details>

### 継続的なアップデートとサポート

V1 はサポートを終了しており、新機能追加・不具合修正は行われません。V2 は継続的にアップデートが提供されます。

## 移行手順

### 1. VCC に V2 リポジトリ*を登録する

VCC（VRChat Creator Companion）を開き、**Settings → Packages** の項目から "Azukimochi" のリポジトリにチェックが入っているか確認してください。

チェックが入っていない場合は、[V2 チュートリアル](/docs/v2/tutorial/howtouse-basic) のVCC登録手順を参照してリポジトリURLを登録してください。

<details>
    <summary> *用語解説 </summary>

**リポジトリとは？**  
パッケージ（ツール）の配布元となるURLのことです。VCC にリポジトリを登録することで、そこで配布されているツールをVCC上から検索・インストール・アップデートできるようになります。

</details>

### 2. プロジェクトに V2 をインストールする

VCC のプロジェクトページから **Manage Packages** を開き、**Light Limit Changer** の最新バージョンをインストールします。

### 3. LLC V1を削除して、 LLC V2を導入する

アバター階層から V1 の LLC プレハブ（`LightLimitChanger` など）を削除します。  
次にヒエラルキーの導入したいアバターを右クリックして、メニューのLightLimitChangerから、Setupを選択して設定します。

### 4. 設定を移行する

V1 で使用していた設定（明るさ範囲・プリセットなど）を V2 コンポーネントで再設定します。  
V2 の各設定項目の詳細は [機能解説ページ](/docs/v2/description/disc_feature) をご参照ください。

---

## 注意事項

:::caution
- **V1 と V2 の同時導入は非推奨です。** 同一アバターに V1・V2 を両方設置すると、パラメーターや処理が競合する可能性があります。
- **V2 は Unity 2019 に対応していません。** LLC v2.0.0 以降は Unity 2022.3.6f1 以降が必要です。VRChat 推奨バージョンの Unity をご使用ください。
:::
